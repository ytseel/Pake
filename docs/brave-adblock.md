# Brave adblock-rust integration (Windows)

This fork integrates Brave's `adblock` Rust crate with the Windows WebView2
request pipeline.

## What is included

- Brave `adblock-rust` network rule engine.
- EasyList and EasyPrivacy subscriptions.
- A local filter cache under the Pake app's config directory (`adblock/`).
- Background list refresh while the app is running.
- A small built-in fallback rule set for the first launch/offline startup.
- WebView2 `WebResourceRequested` interception for all resource contexts.
- Per-process shared engine and in-memory request counters.

## Enable / disable

The `WindowConfig.enable_adblock` field defaults to `true` for Windows builds.
To turn it off for a particular generated app, add this to its window object in
`src-tauri/pake.json`:

```json
"enable_adblock": false
```

If the app is generated by the CLI, add the field to the generated
`src-tauri/pake.json` after generating the app and before compiling it.

## Build

Use the repository's pinned Rust toolchain (see `rust-toolchain.toml`) and
build on Windows with the WebView2 runtime installed:

```powershell
cargo check --manifest-path src-tauri/Cargo.toml
```

Then use the normal Pake Windows packaging workflow.

## Important limitations

- This implementation currently hooks Windows WebView2 only. macOS WKWebView
  and Linux WebKitGTK builds do not use this network interception adapter.
- The engine applies network rules. Full uBlock Origin scriptlet/resource
  replacement support and dynamic cosmetic-filter injection are not yet
  wired into the page lifecycle.
- Filter lists are downloaded after startup on a background thread. The
  built-in fallback rules are active immediately; the full EasyList and
  EasyPrivacy rules become active when the first refresh finishes.
- The request counters are currently internal Rust state; no settings window
  or badge UI is included yet.
- YouTube/YouTube Music may change ad delivery. No filter engine can promise
  that every ad is blocked. Avoid blanket blocking Google video/media hosts:
  those hosts also deliver legitimate playback.

## Filter sources

- EasyList: https://easylist.to/easylist/easylist.txt
- EasyPrivacy: https://easylist.to/easylist/easyprivacy.txt

Filter lists are community-maintained and can change independently of Pake.
